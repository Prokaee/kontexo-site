# Datenschutz dieser Seite

Diese Seite setzt keine Cookies, lädt nichts von Dritten nach und zählt keine Besucher. Schrift und Bilder liegen auf demselben Server.

Dieser Server gehört GitHub Pages, einem Dienst von GitHub aus den USA; wie jeder Server, der eine Seite ausliefert, erhält er dabei eure IP-Adresse.

Was ihr ins Kontaktfeld schreibt, bleibt in eurem Browser und geht nur in eure eigene Mail.
